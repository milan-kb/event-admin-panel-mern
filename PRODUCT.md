# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Event administrators creating, reviewing, updating, and deleting events. Assessment evaluators verify the complete MERN workflow.

## Product Purpose

Keep event details and registration totals in one working administrative interface.

## Operating Context

A responsive React application backed by Express and MongoDB Atlas, hosted on Vercel. The assessment requires Dashboard and Add Event navigation and full event CRUD.

## Capabilities and Constraints

Preserve Event ID, name, description, date, venue, total registrations, search, upcoming/past filters, add, update, delete, validation, errors, loading, and empty states. Registration totals default to zero; attendee registration creation is outside the implemented assessment scope. Preserve the existing API and stored records. No authentication is currently implemented.

## Brand Commitments

The user confirmed on 26 October 2026: retain Gather and all existing features; replace the visual design only. The user explicitly requests an Apple.com-inspired aesthetic, interpreted as typographic clarity, restraint, and precise material treatment rather than Apple branding or a copy of its pages.

## Evidence on Hand

The original Tech Meetup record in Atlas. The existing dashboard and add/edit form. No customer claims, attendee records, event photography, or testimonials have been supplied; do not fabricate them.

## Product Principles

- Event management is the primary task.
- Keep required event details easy to locate.
- Preserve data and working behavior during visual changes.
- Use clear labels and responsive controls.
